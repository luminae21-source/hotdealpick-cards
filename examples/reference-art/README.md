# 독립 생성 참고 시안

쿠팡·토스·네이버 각각 한 번씩 별도로 생성한 전체 카드입니다. 콜라주를 잘라 확대하지 않았습니다. 원본은 1122×1402이며 내용 변경·분할 없이 1080×1350으로 규격을 맞췄습니다.

상품·가격은 사용자가 제공한 2026-10-31 참고 구성입니다. 현재 가격 검증이나 실제 판매 상품 사진이 아니므로 운영 데이터로 사용하지 않습니다. 각 이미지에도 참고 시안 표시가 있습니다.

재사용 가능한 실제 템플릿은 `card.html` + `assets/social-card.css` + `assets/mascots/`입니다. `data/`에 실제 사진·정보를 넣으면 글자와 상품이 교체됩니다.
