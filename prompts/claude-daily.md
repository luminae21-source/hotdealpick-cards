# Claude에 전달할 작업 요청문

아래 내용을 복사하고 대괄호 부분에 실제 자료를 넣으세요.

```text
이 저장소의 CLAUDE.md, FILL.md, SOCIAL_WORKFLOW.md를 먼저 읽어 주세요.

작업명: [영문/숫자 작업명]
몰: [coupang / toss / naver / all]
상품 수: [3 / 4 / 5]
사용 채널: Threads, Instagram 피드
규격: 1080×1350, 4:5, 파일 하나당 독립 카드 한 장

제공 상품 자료:
[몰별 상품명 / 사진 / 가격 / 쿠폰·회원 조건 / 수량·용량 / 실제 링크 / 실제 확인시각]

1. templates/<몰>-<개수>.json 또는 npm run new -- --mall <몰> --name <작업명> --count <개수>로 빈 초안을 만드세요.
   원본 배경은 assets/tpl/<몰>-<개수>.png를 자동 사용합니다. 칸을 삭제하거나 그림을 자르지 마세요.
2. 제공받았거나 실제 판매 페이지에서 확인한 값만 data/ JSON에 입력하세요.
3. 쿠팡, 토스, 네이버의 상품·조건·링크를 각각 분리하세요.
4. 실제 상품 사진을 사용하세요. 고양이·강아지는 마스코트이며 상품 사진을 대신하지 않습니다.
5. 공통 로고, 제휴고지, 레이아웃, 캐릭터 파일은 유지하세요.
6. 날짜를 현재 시각으로 임의 갱신하거나 확인하지 않은 가격을 만들어 넣지 마세요.
7. npm run pack을 실행하고 PNG를 직접 확인하세요. 이미지 누락과 글자 잘림을 보고하세요.
8. social/의 PNG, 스레드 문구, 인스타 문구, alt.txt, links.json을 함께 전달하세요.
9. 같은 데이터를 다른 몰에 복사하거나 콜라주를 잘라서 개별 파일을 만들지 마세요.
10. GitHub 반영을 요청받으면 수정한 데이터·이미지를 커밋하고 Actions 결과를 확인하세요.

확인이 필요한 값은 구체적으로 알려 주세요. SNS에 실제 게시한 것처럼 보고하지 마세요.
```

자연스러운 본문은 ‘장바구니 담기 전에 가격을 확인해 보세요’처럼 짧고 담백하게 작성합니다. 구매·사용한 적이 없으면 체험담을 쓰지 않고, 과장된 효능이나 확인되지 않은 할인·최저가 주장을 넣지 않습니다.
