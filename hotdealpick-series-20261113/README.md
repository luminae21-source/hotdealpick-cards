# 핫딜픽 · 장바구니 & 꾸준템 시리즈

두 시리즈 × 쿠팡·네이버·토스 × 3·4·5개 = **독립된 18개 서식**입니다.
모든 카드는 1080×1350(4:5)이며 블로그·Threads·Instagram에서 쓸 수 있습니다.

## 먼저 열기

`index.html`을 열면 몰·시리즈·상품 수별로 미리보고 PNG와 SVG를 골라 받을 수 있습니다.
`previews/`는 **상품 입력 전 디자인 서식**입니다. 실제 판매 정보가 아니며 그대로 게시하지 마세요.
`templates/`의 SVG는 글자·색·배치를 편집할 수 있는 원본입니다. `assets/`와의 상대 위치를 유지하세요.

## 포함 파일

| 경로 | 내용 |
|---|---|
| previews/ | 빈 서식 PNG 18장 |
| templates/ | 편집 가능한 SVG 18개 |
| data/ | 가짜 값 없는 JSON 초안 18개 |
| assets/mascots/ | 장보기·주방·집콕·겨울, 투명 PNG 4종 |
| src/ | 렌더러·검증·단가 계산 |
| docs/series-plan.md | 꾸준템 회차 구성과 캐릭터 순환 |
| docs/caption-templates.md | 블로그·Threads·Instagram 문구 서식 |
| CLAUDE_HANDOFF.md | 클로드 인수인계 |

## 실제 카드 만들기

Node.js 22 이상, Noto Sans CJK KR 글꼴이 필요합니다. PNG 미리보기는 글꼴 설치 없이 볼 수 있습니다.
Ubuntu에서 글꼴은 `sudo apt-get install fonts-noto-cjk`로 설치할 수 있습니다.

이 **하위 폴더 안에서** 실행합니다. 기존 저장소 루트의 렌더러와 명령은 유지합니다.

```bash
npm ci
npm test
npm run check
```

1. `data/steady-coupang-3.json` 등을 새 파일로 복사합니다.
2. 실제 확인한 상품명·가격·확인 시각·구매 링크를 넣습니다. 사진은 해당 실물 상품 파일을 `assets/images/`에 저장하고 그 경로를 넣습니다. 이미지 URL을 임의로 만들거나 캐릭터를 상품 사진으로 쓰지 않습니다.
3. 사진이 없으면 `img`를 비워 두세요. 완성 카드에는 ‘사진 미제공’이 표시됩니다.
4. 아래처럼 렌더링한 후 PNG와 본문을 확인합니다.

```bash
npm run render -- --data data/내-상품.json --theme pantry --episode 02 --topic "주방의 기본"
```

`output/`에 PNG, 독립적으로 열리는 SVG, 본문 TXT, 대체텍스트 TXT가 생성됩니다. SNS에 자동 게시하지 않습니다.
원본 18개 서식을 다시 만들 때는 `npm run templates`를 실행합니다. 이 명령은 배포 초안과 미리보기를 재생성하므로 실제 운영 데이터는 다른 파일명으로 보관하세요.

## 두 시리즈의 역할

- **오늘의 장바구니**: 해당 회차에 확인한 상품 3~5개를 묶는 카드.
- **꾸준템 시리즈**: 주방·생활·계절처럼 주제를 정해 여러 회차로 이어가는 카드. 특정 상품의 판매량·장기 인기·재구매를 검증했다는 뜻으로 쓰지 않습니다.
- 회차는 `--episode 01`, 주제는 `--topic "생활의 기본"`으로 관리합니다.
- 테마는 `market`, `pantry`, `home`, `season` 중 선택하며 모든 몰에 공통 적용할 수 있습니다. 하단 그림은 자동으로 다른 포즈를 사용합니다.

## 데이터·가격 규칙

기존 상품 JSON의 루트 `mall,title,checked,items`와 상품 `name,price,cond,unit,img,url,checked`를 유지합니다. 새 디자인의 회차·테마는 CLI 옵션으로 분리했습니다.
가격·상품 확인 시각이 모두 있는 행만 노출하고, 유효한 행이 3개 미만이면 생성을 중단합니다. 모든 표시 행에 실제 상품명과 해당 몰 HTTPS 링크가 필요합니다.
몰 혼합, 판매처 칸, 정가, 할인율, 최저가·효능·허위 체험 주장은 넣지 않습니다. 제휴고지 22px, 상품명 32px, 가격 44px입니다.
토스는 하단 게시 시점 가격 줄이 필수입니다. 조건은 확인된 와우가·쿠폰가·회원가만 표시합니다.

단가는 총 수량·총 용량으로 계산하고 원 단위 반올림합니다. 예시 숫자는 계산 설명용입니다.

```bash
node src/unit.mjs 13900 60
# 232원 (13,900원 ÷ 60개)
node src/unit.mjs 6640 840 100
# 790원 (100mL당)
```

첨부 이미지의 ‘13,900원 / 60개 / 개당 483원’은 서로 맞지 않습니다. 실제 상품 구성과 적용 가격을 확인한 뒤 계산하세요. 이 패키지는 첨부 제품 가격을 최신 가격으로 재검증하지 않았습니다.

가격 조건·단가 근거·단축 링크의 실제 도착 상품은 사람이 원본 페이지와 대조해야 합니다. 단순 형식 검사는 상품 진위를 보장하지 않습니다.

## GitHub와 클로드

이 폴더를 기존 `hotdealpick-cards` 저장소의 독립 하위 폴더로 추가하면 됩니다. 기존 3·4·5개 템플릿과 성에제거제 작업은 덮어쓰지 않습니다.
클로드는 `CLAUDE_HANDOFF.md`부터 읽고 작업하세요. GitHub에 파일이 있다는 사실만으로 Claude MCP나 SNS 자동 게시가 연결되는 것은 아닙니다.

캐릭터는 이미지 생성 도구로 각각 독립 생성했습니다. 원문 프롬프트는 `docs/mascot-prompts.json`에 있습니다. 가격·텍스트·번호는 코드로 렌더링합니다.
