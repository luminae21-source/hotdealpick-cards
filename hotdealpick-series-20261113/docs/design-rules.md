# 디자인 기준

- 1080×1350 세로. 1파일=1완성 카드. 콜라주·격자·분할 확대 금지.
- 쿠팡: 살구빛 바탕 / 네이버: 연녹색 바탕 / 토스: 하늘색 바탕. 글자 기본은 핫딜픽 네이비 #223845, 보조는 청록 #426765.
- 큰 제목과 노란 곡선 밑줄은 상단에 유지. 캐릭터 그림이 제목이나 제휴고지에 겹치지 않게 배치.
- 상품 카드는 둥근 흰 칸, 번호는 단순한 둥근 네모. 붉은 가격은 오른쪽 정렬.
- 제휴고지 22px, 상품명 32px, 실제 가격 44px. 상품명은 두 줄까지만 허용.
- 가격 조건은 가격 위에 붙이고 단위 가격은 아래 연노란 칩에 표시.
- 가격 확인 시각은 상품별로 표시. 토스에는 하단 게시 시점 가격 줄도 유지.
- 실제 상품 사진은 종횡비를 유지. 생성 캐릭터를 실제 제품 사진으로 대신 사용하지 않음.
- 마스코트 테마 4종은 모든 몰에 사용 가능. 상단/하단에는 다른 테마를 짝지음.
- 상품별 실제 가격·링크가 없는 현재 PNG는 명확히 디자인 서식으로 표기.
