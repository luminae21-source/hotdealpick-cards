# Claude 인수인계 · 장바구니와 꾸준템

이 폴더의 README.md → docs/series-plan.md → data/ → previews/ 순서로 읽으세요.
사용자가 승인한 핫딜픽 캐릭터와 큰 제목·노란 밑줄·둥근 흰 상품 칸을 유지합니다.

1. 쿠팡·네이버·토스는 카드마다 하나만 사용합니다. 제휴고지는 src/config.mjs의 고정 문구를 유지합니다.
2. `오늘의 장바구니`와 `꾸준템 시리즈` 둘 다 3·4·5개를 지원합니다. 데이터 파일 하나에 3~5개만 넣습니다.
3. `previews/`는 상품 입력 전 서식입니다. 빈 샘플을 실제 상품 카드나 게시 완료로 보고하지 않습니다.
4. 꾸준템은 회차별 생활 주제 시리즈입니다. 판매 이력 없이 ‘베스트셀러’, ‘재구매 인증’, ‘오래 검증된 제품’ 같은 근거 없는 문구를 만들지 않습니다.
5. 실제 가격·조건·수량·확인 시각·구매 링크만 넣습니다. 현재 시간을 확인 시각으로 자동 복사하지 않습니다. 각 상품의 확인 시각과 게시 기준 시각을 구분합니다.
6. `unit`은 확인된 총 수량·용량으로 계산해 넣습니다. `node src/unit.mjs 가격 총수량 [비교단위]`를 사용할 수 있습니다. 13,900원÷60개는 232원이며 483원을 복사하지 않습니다.
7. 상품 사진은 실제 상품만 사용합니다. assets/images/에 저장하고 경로를 입력합니다. 사진이 없으면 빈 값으로 두며 마스코트나 생성된 가짜 제품 사진으로 대체하지 않습니다.
8. JSON 스키마는 기존과 같고 디자인 옵션은 명령줄로 전달합니다. `--theme market|pantry|home|season`, `--episode 01`, `--topic "주방의 기본"`.
9. 사진 원본은 비율을 유지합니다. 상품명은 32px·두 줄 이내, 가격 44px입니다. 넘치면 글자를 과도하게 줄이거나 잘라 숨기지 말고 사용자에게 정확한 짧은 명칭을 요청하세요.
10. 위·아래 캐릭터는 서로 다른 테마/포즈를 사용합니다. 4종 그림을 순환하고, 같은 스티커를 연속 3일 이내 재사용하지 않도록 최근 게시 이력도 확인하세요. 이 코드가 게시 이력을 자동으로 확인하지는 않습니다.
11. 하위 폴더에서 `npm ci`, `npm test`, `npm run check`, `npm run render -- --data ...`를 실행합니다. 새 카드 PNG의 글자 겹침·잘림·사진·가격 조건을 직접 확인합니다.
12. 제품·가격 입력만 할 때 코드나 검사를 약화하지 않습니다. 디자인 변경은 별도 요청 범위에서만 합니다. GitHub 반영은 이 폴더 안으로 제한하고 다른 작업을 덮어쓰지 않습니다.
13. 결과 PNG·본문·대체텍스트·제외 상품과 이유를 전달합니다. SNS 게시 권한이나 연결 없이 게시됐다고 말하지 않습니다. API 키·비밀번호를 파일이나 커밋에 넣지 않습니다.

사용자가 새 회차를 요청하면 주제와 몰에 맞는 JSON 복사본부터 만드세요. 자료가 빠진 항목은 사실대로 비워 두고 확인 필요 사항을 알려 주세요.
