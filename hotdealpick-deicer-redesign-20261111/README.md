# 핫딜픽 · 성에제거제 6종 재디자인

블로그·쓰레드·인스타그램 공용 **1080×1350 PNG 4장**입니다. 첨부 시안의 가격을 유지하고, 편집 가능한 텍스트와 정확한 막대 길이로 다시 구성했습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| exports/01-cover.png | 대표 이미지 |
| exports/02-unit-price.png | 100mL당 가격 비교 |
| exports/03-price-list.png | 6종 표시 판매가·구성 |
| exports/04-shopping-note.png | 구매 전 확인사항 |
| exports/*.svg | 글자를 편집할 수 있는 벡터 원본 |
| assets/*.png | 독립적으로 생성한 캐릭터 그림 2종 |
| data/products.json | 가격·용량·묶음 수·조건·자료 기준 시각 |
| src/render.mjs | 데이터로 SVG·PNG를 만드는 렌더러 |
| docs/captions.md | 쓰레드·블로그 본문과 대체텍스트 |
| CLAUDE_HANDOFF.md | 클로드 작업 지침 |

## 실행

Node.js 20 이상과 한국어 글꼴 **Noto Sans CJK KR**이 필요합니다.

```bash
npm install
npm run build
npm run check
```

Ubuntu에서는 `sudo apt-get install fonts-noto-cjk`로 글꼴을 설치할 수 있습니다. 결과는 exports 폴더에 생성됩니다. index.html을 열면 4장을 확인할 수 있습니다. SVG는 해당 글꼴이 있는 환경에서 편집하세요. PNG는 글꼴 설치 없이 그대로 사용할 수 있습니다.

가격은 그림 생성으로 쓰지 않고 JSON에서 계산해 텍스트로 렌더링합니다. 캐릭터 그림만 이미지 생성으로 제작했습니다. 상품 사진을 새로 만들어 실물인 것처럼 쓰지 않습니다. 이 구현은 브라우저 캔버스를 저장하지 않으므로 상품 이미지 CORS에 의존하지 않습니다.

## 데이터의 범위

- 출처: 사용자가 제공한 원본 시안. 표기 시각은 **2026-11-11 18:00**입니다.
- 외부 판매 페이지에서 가격·조건을 새로 확인한 자료가 아닙니다.
- 계산: 판매가 ÷ (한 통의 용량 × 통 수) × 100, 원 단위 반올림.
- 결과: 790 / 937 / 1,001 / 1,700 / 2,132 / 2,180원.
- ‘약 2.8배’는 이번 6종 내 높은 단위 가격과 낮은 단위 가격의 비율입니다. 성능 차이 또는 시장 전체 최저가라는 의미가 아닙니다.
- 지엔의 와우·쿠폰 조건과 소낙스의 와우 조건은 원본에 있는 항목만 유지했습니다. 할인율은 덜어냈습니다. 빈 조건은 조건이 없다고 검증했다는 뜻이 아닙니다.
- 구매 링크·상품 사진 주소는 제공되지 않아 비워 두었습니다. 임의로 만들지 마세요.

## 디자인

민트 #E8F4F1 / 청록 #426765 / 네이비 #223845 / 빨강 #F33430. 노란 밑줄은 표지에만 사용합니다. 그림자는 최소화하고, 붉은색은 가장 낮은 단위 가격과 브랜드에 제한합니다. 위의 제휴 안내는 모든 장에 고정합니다.

이번 작업은 **6종을 비교하는 편집형 콘텐츠**입니다. 기존 ‘오늘 살 만한 딜’ 상품 카드의 3·4·5개 구성 규칙을 바꾸는 작업은 아닙니다.

## 검증

6개 단위 가격 계산, 4장의 크기, 제휴 문구, 확인 시각을 자동 확인했습니다. 각 페이지는 별도의 SVG에서 독립적으로 렌더링하며 콜라주를 잘라 만들지 않습니다. GitHub 업로드와 SNS 게시 완료 여부는 별도로 확인해야 합니다.
