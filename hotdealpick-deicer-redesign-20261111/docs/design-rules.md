# 편집 규칙

- 캔버스 1080×1350, 좌우 여백 64px.
- 제휴 안내 22px 이상, 모든 장 맨 위. 정확한 문구: “이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.”
- 제목 64~76px, 상품명 30px 이상, 주요 가격 40px 이상. 설명은 26~32px, 출처는 21~23px.
- 정보 우선순위: 질문 → 핵심 숫자 → 비교 자료 → 기준 시각과 구매 안내.
- 캐릭터는 표지의 겨울 차량 장면과 마지막 장의 체크리스트 장면으로 사용. 데이터가 많은 2·3장은 장식을 덜어 가독성 유지.
- 브랜드 로고는 빨간 둥근 사각형 ‘딜’ + ‘핫딜픽’. 쇼핑몰 로고 이미지와 큰 할인 배지는 사용하지 않음.
- 제목 아래 노란 붓선을 한 번만 사용. 굵은 외곽선·그림자·반복 스티커는 추가하지 않음.
- 데이터는 그림과 분리하여 관리. 색이 단위 가격 순위를 왜곡하지 않도록 수치와 막대 길이를 동일 비율로 계산.
- 보관 장소를 특정해 권장하지 않고 제품의 사용·보관 표시를 확인하도록 안내.
- 원본 자료에 없는 배송비·링크·성능·리뷰 수는 추가하지 않음.

## 캐릭터 생성 기록

캐릭터 2종은 내장 이미지 생성으로 각각 독립 제작했습니다. 원본 제품 사진을 재현하는 대신, 겨울 차량 관리 장면과 구매 체크리스트 장면을 사용했습니다. 가격표와 막대그래프는 생성 이미지가 아닌 코드 기반 정확한 조판입니다.

그림 프롬프트 요약: golden retriever with red scarf + white-orange-black calico cat with yellow star hairclip, warm precise tapered outlines, nuanced soft dimensional shading, premium animation illustration, natural connected paws, transparent background, no lettering, no product packaging, no collage. 표지는 성에가 있는 민트색 차량 옆에서 생각하는 포즈, 마지막 장은 나란히 앉아 빈 체크리스트를 보는 포즈입니다.
